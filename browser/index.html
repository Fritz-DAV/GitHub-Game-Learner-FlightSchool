Flight School Browser Edition

A small flying game

Take the controls.

Choose an aircraft, pick two airports, and fly there. This is a simplified learning game, not a flight simulator.

First flight

Try the Cessna in calm weather. Add full throttle, steer along the runway, then gently raise the nose around 55–60 knots. Follow the destination bearing and line up with its runway before landing.

Game performance figures are not real-world operating guidance. Never use this game for real flying advice.
